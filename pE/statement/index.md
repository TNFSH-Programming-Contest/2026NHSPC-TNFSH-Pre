本題是 two-step 題型

南宮柳棲今天邀請了資訊社的大家參加他的派對。派對中有一個超大超大的蛋糕，從左到右編號為第 $0$ 段至第 $n-1$ 段，每一段蛋糕都有各自的「柳棲程度」 $a_i$。

為了追求公平，蛋糕必須被徹底切分，直到所有蛋糕都被切成單獨的 $n$ 小塊為止。對於任何一段連續的蛋糕區間 $[l, r]$，切蛋糕的人可以選擇在位置 $k$（$l \le k < r$）切一刀，將其分成 $[l, k]$ 與 $[k+1, r]$ 兩塊。

然而，每當對區間 $[l, r]$ 切下一刀時，柳棲想要跳起來大喊「6767」的衝動值，會增加\textbf{「切割前該區間 $[l, r]$ 的柳棲程度總和」}。

這場派對的切蛋糕任務將由柳棲與巴漆合作完成。柳棲有著預知未來的能力，他已經提前知道了整條蛋糕的柳棲程度 $a_0, a_1, \dots, a_{n-1}$。但是，在派對上實際負責切蛋糕的巴漆\textbf{並不知道任何 $a_i$ 的資訊}。

為了讓派對順利進行，柳棲只能在派對開始前，傳送一段長度不超過 $B$ 個位元的二進位編碼給巴漆。

派對開始後，現場會出現 $Q$ 個突發猜想的詢問。每次詢問會給定一個區間 $[l, r]$，巴漆必須根據柳棲傳來的密碼，回答：\textbf{如果只拿出區間 $[l, r]$ 的蛋糕出來進行徹底切分，為了讓最終「大喊 6767 的衝動值」總和最小，第一刀應該切在哪個位置 $k$？}

## 互動說明

本題分為兩個階段，你需要實作兩個獨立的程式碼檔案。這兩個階段會被評測機在\textbf{不同的進程}中執行，無法共用任何全域變數。

### 階段一：柳棲的預知並且進行編碼
你需要實作以下函式：

`std::string encode(int n, std::vector<int> a);`

 - `n`：蛋糕的總段數。
 - `a`：長度為 $n$ 的陣列，代表每段蛋糕的柳棲程度
 - 你需要回傳一段僅包含字元 `0` 與 `1` 的 `std::string`。

### 階段二：巴漆的解碼與處理詢問
在階段開始前，系統會先呼叫你的 `decode` 函式一次。

`void decode(int n, std::string S);`

 - `n`：蛋糕的總段數。
 - `S`：柳棲在第一階段回傳的二進位字串。

接著，系統將會呼叫 $Q$ 次 `query`：

`int query(int l, int r);`

 - `l`, `r`：代表本次詢問的蛋糕區間 $[l, r], (0 \le l < r \le n-1)$
 - 你需要回傳最佳的第一刀切點 $k$，假如有多個切點符合要求，回傳任一一個即可。

\clearpage

## 評分標準

假如你的 `encode` 函式回傳的字串長度超過 $B$，則你會拿到 \textbf{Wrong Answer(1)}。

假如你的 `query` 函式回傳的切點不是合法的，則你會拿到 \textbf{Wrong Answer(2)}。

假如你的 `query` 函式回傳的切點不是最佳的，則你會拿到 \textbf{Wrong Answer(3)}。

## 輸入限制
 - $2 \le n \le 2000$
 - $1 \le a_i \le 10^9$
 - $1 \le Q \le 10^5$
 - $B = 4 \cdot 10^6$
